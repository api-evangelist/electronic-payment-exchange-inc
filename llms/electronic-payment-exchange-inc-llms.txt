# Electronic Payment Exchange (EPX)

> EPX is a full-stack, PCI-compliant payments platform (part of North / North American Bancard) acting as ISO, merchant acquirer, gateway, and front- and back-end processor. Its BRIC technology tokenizes every transaction so cardholder data never touches the merchant environment. Developers integrate via Hosted Checkout, the Hosted Pay Page, the Browser Post API, and the North EPX Custom Pay REST API.

## APIs

- [EPX Payments API](https://developer.north.com/): Hosted Checkout, Hosted Pay Page, Browser Post API, and Custom Pay REST API for sales, authorizations, captures, refunds, voids, recurring billing, and batch settlement. Production host https://secure.epx.com, UAT host https://secure.epxuap.com.

## Authentication

- Legacy four-part processing key (CUST_NBR, MERCH_NBR, DBA_NBR, TERMINAL_NBR) on Browser Post / Hosted Pay Page requests.
- EPI-Id + EPI-Signature (+ EPI-Trace) HMAC-style signed headers for the Custom Pay REST API.
- No OAuth 2.0 / OIDC surface.
